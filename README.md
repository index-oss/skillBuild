# SkillBuild / ( Forge AI ) 

> An advanced platform designed to enhance your learning journey, master new technical skills, and track your progress effortlessly.

---

## ✨ Features
- 🎯 **Skill Tracking:** Monitor your learning milestones and achievements in real-time.
- 📚 **Curated Resources:** Access hand-picked tutorials, guides, and practice exercises.
- ⚡ **Interactive Interface:** Clean, responsive, and modern UI built for optimal productivity.

---

## 🛠️ Tech Stack
- **Framework:** Next.js (TypeScript). 
- **Styling / Components:** Tailwind CSS / PostCSS. 
- **Backend & Database:** Supabase.

---

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps:

```bash
# Clone the repository
git clone [https://github.com/index-oss/skillBuild.git]

# For run the directory localhost/5000
pnpm build or pnpm dev

```
